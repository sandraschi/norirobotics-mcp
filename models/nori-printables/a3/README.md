# A3 printables

Printable parts for the NORI A3.

| Part | Type | Description | Rev |
|---|---|---|---|
| [ear-pucks](ear-pucks/) | cosmetic | Purely cosmetic covers for the speaker holes on the sides of the head | 1 |
| [head-pegs](head-pegs/) | cosmetic | Purely cosmetic pegs for attaching ears, printed icons, etc. to the head | 1 |
| [gripper-attachment-points](gripper-attachment-points/) | end effector | Gripper mounting-interface geometry for designing custom end effectors | 1 |

**Type** is one of: `spare` (printable replacement), `end effector`
(attachment-point geometry for custom tools), `cosmetic` (covers and trim).
